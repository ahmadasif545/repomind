# Code of Conduct

## Our Pledge

We want Repomind to be a friendly, welcoming project for everyone, regardless of experience level, background, gender, nationality, religion, age or ability.

## Expected behavior

- Be respectful and patient, especially with beginners
- Give and accept constructive feedback
- Focus on what is best for the community
- Assume good intent

## Unacceptable behavior

- Harassment, insults, discrimination or personal attacks
- Trolling or deliberately derailing discussions
- Publishing others' private information
- Spam or unrelated self-promotion

## Enforcement

Maintainers may edit or remove comments, issues and contributions that break this code, and may ban repeat offenders.

Report problems by opening a private security advisory on the repo or contacting the maintainer through their GitHub profile: https://github.com/ahmadasif545

This Code of Conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org), version 2.1.
