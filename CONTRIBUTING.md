# Contributing to Repomind

Thanks for helping! All kinds of contributions are welcome: bug fixes, features, docs and design.

## Getting started

```bash
git clone https://github.com/ahmadasif545/repomind.git
cd repomind
npm install
npm run dev
```

## Making a change

1. Fork the repo and create a branch: `git checkout -b feature/short-name` (or `fix/short-name`)
2. Make your change. Keep it focused on one thing.
3. Test it in the browser with a public repo and, if relevant, a private one.
4. Commit with a clear message: `git commit -m "Add dependency view for Python files"`
5. Push and open a Pull Request describing **what** changed and **why**. Add a screenshot for UI changes.

## Guidelines

- Keep pull requests small and focused.
- Match the existing code style.
- Never commit API keys, tokens or `.env` files.
- Don't add heavy dependencies without discussing in an issue first.
- Be kind. See the [Code of Conduct](./CODE_OF_CONDUCT.md).

## Reporting bugs

Open an issue and include: what you did, what you expected, what happened, your browser and OS, and a screenshot if possible. **Never paste tokens or keys.**

## Ideas

Open an issue or start a Discussion before building something big, so we can agree on the approach first.
